Conga Platform Inspector was removed

Thanks for using it. Here's what that means for your saved data.

Your saved data was deleted with it

Favorites, saved queries, query history, settings, pinned objects and flag favorites lived inside the extension, so Chrome removed them too. If you exported a backup before removing it, you can bring everything back.

Installing a new version?

  1. Load the new version: chrome://extensions → Developer mode → Load unpacked.
  2. On the welcome page that opens, click Import a backup file and pick your backup.

Next time: keep your data without a backup

  • Replace the files in the same folder with the new version, then click ↻ Reload on chrome://extensions. Nothing is lost.
  • Before removing the extension or loading it from a different folder, export first: panel → Settings → Backup & Share → Export.
